# Buildings Asset Specifications

- Target Polycount: 10,000 - 45,000 tris per modular structure.
- LOD System: LOD0 (100%), LOD1 (50%), LOD2 (25%), LOD3 Collision Hull.
- Texture Format: SurfaceAppearance PBR (ColorMap, MetalnessMap, NormalMap, RoughnessMap) up to 1024x1024.
- Collision: Separate non-rendered Hull meshes with CanCollide=true, CollisionFidelity=Box or PreciseConvexDecomposition.
